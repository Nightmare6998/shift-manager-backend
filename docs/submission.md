# Before submitting

- Make the GitHub repo public. Open it while signed out to check.
- Add the real repo URL and live backend URL to your school submission.
- Open the live `/health` URL. It should return 200.
- Start a fresh clone using only the README. Run the smoke test.
- Run `docker compose down`, then `docker compose up -d`. Log in again to show the database kept the account.
- Save local and live smoke test output. Save startup logs, `docker compose ps`, and `git log --oneline --graph`.
- For the separate broken-deploy lesson, use the school's starter repo. Save the failed request, relevant logs, actual fix, and passing request after restart. Do not invent a failure or reuse example output as your own.
- Be ready to explain the code. The course requires this even when using AI.

Do not open the timed final until both public URLs work. Discussion participation and review deadlines are separate school tasks.
